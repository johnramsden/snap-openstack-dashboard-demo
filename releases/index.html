How a commit is established

  • git tag the publish workflow tagged the commit it built.
  • git-info.txt the build wrote the commit into the package.
  • version string parsed from the snap's version, which its build stamps with the commit. A convention, not recorded metadata.
  • unknown no mechanism resolved this revision. Hover it for why.
  • · nothing is published on that risk, for the selected architecture.
